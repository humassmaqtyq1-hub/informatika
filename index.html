Struktur File Deployment (Vercel)

Simpan seluruh file HTML berikut dalam satu folder root repositori GitHub Anda agar tautan antar-bab otomatis berjalan di Vercel:

informatika-sma/
├── index.html (Wadah Utama)
├── kelasXbab1.html (Berpikir Komputasional)
├── kelasXbab2.html (Sistem Komputer)
├── kelasXbab3.html (Jaringan Komputer X)
├── kelasXIbab1.html (SDLC - File Sebelumnya)
├── kelasXIbab2.html (Jaringan Komputer XI)
└── kelas[X/XI/XII]bab[4..8].html (Slot Bab Berikutnya)
